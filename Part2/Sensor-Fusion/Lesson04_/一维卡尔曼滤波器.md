# 一维卡尔曼滤波器解释

这个一维卡尔曼滤波器用于跟踪行人的位置（p）和速度（v）状态。以下是核心组件和工作流程的解释：

---

**核心组件**

1. 状态向量 (x)
   
   $$
   x = \begin{bmatrix} p \\ v \end{bmatrix}
   $$
   
   • 包含位置 `p` 和速度 `v`

2. 状态协方差矩阵 (P)
   • 表示状态估计的不确定性
   
   • 初始值设为 `P = [[1000, 0], [0, 1000]]`，表示高度不确定

3. 状态转移矩阵 (F)
   
   $$
   F = \begin{bmatrix} 1 & \Delta t \\ 0 & 1 \end{bmatrix}
   $$
   
   • 基于匀速运动模型：新位置 `p' = p + v*Δt`，速度保持不变

4. 测量矩阵 (H)
   
   $$
   H = \begin{bmatrix} 1 & 0 \end{bmatrix}
   $$
   
   • 激光雷达只测量位置，忽略速度信息

5. 测量噪声协方差 (R)
   
   $$
   R = \begin{bmatrix} 1 \end{bmatrix}
   $$
   
   • 表示测量噪声（激光雷达精度）

6. 过程噪声协方差 (Q)
   • 初始设为 `0`（假设理想匀速运动，无外部干扰）

---

**工作流程** **1. 预测步骤 (Prediction)**

```cpp
x = F * x;          // 状态预测：x' = F·x
P = F * P * F.transpose() + Q; // 协方差预测：P' = F·P·Fᵀ + Q
```

• 使用物理模型预测下一时刻的状态

• 不确定性 `P` 随时间增加（`F·P·Fᵀ` 使非对角线元素增大）

**2. 更新步骤 (Update)**

```cpp
VectorXd z = measurements[n];  // 获取传感器测量值
VectorXd y = z - H * x;        // 残差：y = z - H·x'
MatrixXd S = H * P * H.transpose() + R; // 残差协方差
MatrixXd K = P * H.transpose() * S.inverse(); // 卡尔曼增益

x = x + K * y;                 // 状态更新
P = (I - K * H) * P;           // 协方差更新
```

• 残差 (y)：测量值与预测值的差异

• 卡尔曼增益 (K)：权衡预测与测量的可信度

• `S` 较小时（测量可靠），`K` 增大，更信任测量值

• `S` 较大时（测量不可靠），`K` 减小，更信任预测

• 更新后 `P` 减小，表示不确定性降低

---

**处理流程示例** 给定测量序列 `[1, 2, 3]`（单位时间间隔 `Δt=1`）：

1. 初始状态  
   `x = [0, 0]ᵀ`, `P = [[1000, 0], [0, 1000]]`

2. 第一次更新  
   • 预测：`x' = [0, 0]ᵀ`
   
   • 测量 `z=1` → 更新后 `x ≈ [1, 1]ᵀ`
   
   （速度被更新为 `1`，因位置从 `0→1`）

3. 第二次更新  
   • 预测：`x = [1+1*1, 1]ᵀ = [2, 1]ᵀ`
   
   • 测量 `z=2` → 小幅修正位置和速度

4. 第三次更新  
   • 预测：`x = [2+1*1, 1]ᵀ = [3, 1]ᵀ`
   
   • 测量 `z=3` → 状态收敛到 `[3, 1]ᵀ`

---

**关键点** • 传感器融合核心：通过 `K` 动态平衡预测模型和测量数据

• 不确定性管理：`P` 矩阵在预测时扩大，更新时缩小

• 效率：仅需矩阵运算，适合实时系统

• 扩展性：此框架可扩展到多维（如雷达+激光雷达融合）

> 代码中使用的 Eigen 库 提供高效的矩阵运算，实际实现需注意矩阵维度匹配和特殊值处理（如 `S.inverse()` 需检查非奇异）。
